

\# Code of Conduct



\## Our Commitment



We are committed to providing a welcoming, respectful, and inclusive environment for everyone contributing to this project.



\## Expected Behavior



\- Be respectful and professional.

\- Accept constructive feedback.

\- Focus on collaboration and learning.

\- Respect different opinions and experiences.



\## Unacceptable Behavior



Harassment, discrimination, offensive language, and disrespectful conduct are not acceptable.



\## Reporting



Report unacceptable behavior to the project maintainer through GitHub.



\## Reference



This project follows the principles of the \[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code\_of\_conduct/).
